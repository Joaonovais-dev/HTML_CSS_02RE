Projeto Prime

O projeto Prime é um projeto de código aberto que tem como objetivo criar uma plataforma de aprendizado de programação para crianças e adolescentes. O projeto foi criado por um grupo de voluntários que acreditam que a programação é uma habilidade essencial para o futuro e que deve ser acessível a todos.
